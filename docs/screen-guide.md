# たけチャート 画面説明・使い方

[リポジトリのトップへ](../README.md)

## 1. スコアシート

[スコア入力画面を開く](https://taikechiuketa.github.io/mahjong-score/)

| 画面内の項目 | 操作 |
| --- | --- |
| セット設定 | 対局日・伝票番号を確認し、ポイント倍率とチップレートを設定します。 |
| プレイヤーマスター | 「登録・編集」で名前の登録・変更・削除やランキング表示を設定します。「マスターから追加」で今回の参加者を選びます。 |
| 半荘スコア一覧 | 「半荘を追加」で行を作り、半荘ごとに三麻・四人三麻・四人麻雀を選んで整数のポイントを入力します。抜け番は長押しで設定・解除できます。必要人数より1人少ないところまで入力し、残りの空欄を選ぶと、合計が0になる点数を補完します。 |
| チップ・最終精算 | プレイヤーごとのチップ増減を入力します。ポイントとチップを換算した精算結果が表示されます。 |
| データ管理 | 「JSON保存／読込」は現在のセットを対象にします。「全データをバックアップ／バックアップから復元」は現在のセット、履歴、プレイヤーマスターをまとめて扱います。復元は既存データを置き換えるため、先に現状をバックアップしてください。 |

### セットの保存と終了

| ボタン | 操作結果 |
| --- | --- |
| セットを保存 | 現在のセットを履歴に保存します。入力画面で引き続き編集できます。 |
| セットを終了 | 履歴に保存し、進行中のセットを閉じます。その日の対局を終えるときに使います。 |
| 新しいセット | 次のセットを開始します。進行中のセットがあれば確認後に履歴へ保存します。 |

## 2. 通算成績・履歴

| 画面内の項目 | 操作 |
| --- | --- |
| 通算成績 | 期間と対局種目を選びます。期間で「月間ランキング」を選ぶと「対象月」が表示されます。列見出しで並べ替えられます。 |
| 個人成績 | プレイヤー名を押すと詳細を表示します。種目別の成績、順位分布、対戦相手別成績、ポイント・チップ・収支の推移を確認できます。 |
| レーティング | 総合または種目別の現在R、対象半荘数、直近の増減を表示します。プレイヤー名から個人成績とR推移を確認できます。 |
| セット履歴 | 日付と伝票番号でセットを開きます。入力画面では過去セットの編集・削除と雀簿データの追加ができます。過去セットの修正は「セットを保存」で反映します。 |
| DB同期（管理者用） | ログインすると端末データをDBに同期できます。別端末で作業を引き継ぐ場合は、表示された同期状態を確認してから「DBから読み込む」を使います。 |

### 雀簿の履歴を追加する

「雀簿データを追加」でテキストを貼り付け、対局種目を選んで「内容を確認」を押します。取り込む内容を確認してから履歴へ追加します。

## 3. 閲覧専用・セット共有

[閲覧専用ページを開く](https://taikechiuketa.github.io/mahjong-score/results.html)

閲覧専用ページはログインなしで、公開済みの成績・レーティング・セット履歴を確認できます。特定の開催結果を送るときは、セット履歴を開いて「セット共有ページを開く」を選び、「共有リンクをコピー」でURLを取得します。共有ページにはセットの精算結果と半荘別スコアが表示されます。

進行中のセットを共有したいときは「セットを終了」して、管理画面でDB同期の完了を確認します。同じ日付・伝票番号のセットが重複する場合は、対象を一意に指定できないためリンクが出ません。

## 4. ルールブック・点数表

[公式ルールブック・点数表を開く](https://taikechiuketa.github.io/mahjong-score/rules.html)

対局ルール、チップ獲得条件、ペナルティ、マナー、公式点数表と四人麻雀の点数表を掲載しています。公開画面から参照できます。

チップのマイナス入力は赤字で表示します。チップ合計が0枚でないセットを保存すると、合計枚数を示す確認が出ます。セット保存の結果はポップアップで確認できます。

「表示中の通算成績を書き出す」は、現在の期間・種目の通算成績をJSONに保存します。進行中の入力を含む場合は確認画面に表示します。

## 対局入力と成績の表示

「新しいセット」と倍率・チップレートはセット設定に置く。半荘スコア表の上でプレイヤーを選び、表の下で半荘を追加またはセットを保存する。チップ・最終精算はスコア表と同じプレイヤー順の列で表示し、精算表の下に「セットを終了」を置く。入力画面と閲覧用の通算成績・個人成績では、ポイント・収支・チップのマイナス値を赤字で表示する。
