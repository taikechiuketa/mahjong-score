# たけチャート 画面説明・使い方

[リポジトリのトップへ](../README.md)

## 1. 入口とログイン

[記録画面](https://taikechiuketa.github.io/mahjong-score/)を開くと、未ログインならメール・パスワードのログイン画面が表示されます。ログイン済みならDBの最新データを自動で読み込みます。「DBから読み込む」という通常操作は不要です。データがない場合は新しいセットの開始待ちになり、サンプルのプレイヤーは生成しません。

ログイン画面の「成績を見る（ログイン不要）」から[公開成績](https://taikechiuketa.github.io/mahjong-score/results.html)へ移れます。公開成績からは「対局を記録する（ログイン）」で戻れます。

端末とDBが異なり、未送信の入力がある場合は自動で上書きしません。「DBの保存データで開く」「端末のデータで再開」から選びます。どちらを選んでも両方の復旧コピーはこの端末に残ります。端末を選んだだけではDBへ送信しません。

## 2. 4つの画面

| メニュー | 内容 |
| --- | --- |
| 入力 | セット設定、参加者、半荘スコア、チップ・最終精算、セットの保存・終了 |
| 成績 | 保存済みセットの通算成績、期間・種目別集計、レーティング、個人成績 |
| 履歴 | セットの検索・詳細・編集・削除、共有、雀簿データ追加 |
| 設定 | プレイヤーマスター、JSON保存・読込、バックアップ・復元、復旧コピー、接続の詳細、ルールへのリンク |

画面上部にログイン状態・保存状態を表示します。「この端末からログアウト」も上部にあります。

## 3. 対局を記録する

「新しいセット」で開始し、「プレイヤーを選ぶ」で参加者を追加します。倍率とチップレートは入力画面で設定します。プレイヤーマスター全体の登録・編集は「設定」にあります。

| 操作 | 結果 |
| --- | --- |
| 半荘を追加 | スコア表の下に行を追加します。半荘ごとに三麻・四人三麻・四人麻雀を選べます。 |
| 点数入力 | 整数で入力します。必要人数より1人少ないところまで入力し、残りの空欄を選ぶと合計0の点数を補完します。抜け番は長押しで設定・解除します。 |
| チップ入力 | セットの最後に増減枚数を入力します。マイナスは赤字。合計が0でなければ保存時に確認します。 |
| セットを保存 | 端末の履歴に保存したあと、DB保存と公開成績への反映を行います。セットの入力は続けられます。 |
| セットを終了 | 履歴へ保存して進行中セットを閉じ、DBに反映します。 |
| 新しいセット | 進行中があれば確認後に履歴に保存し、次のセットを開始します。 |

入力途中は端末に一時保存されます。端末保存だけでは別端末や公開ページには反映されません。履歴の編集中も入力を端末で保護し、「設定 → 保護した入力を確認」から再開できます。

「保存済み・公開成績にも反映しました」が成功表示です。DB保存だけ成功した場合は「DBに保存済み・成績ページへの反映待ち」と表示します。「設定 → 接続・保存の詳細 → 入力を保存・保存を再試行」から再送信できます。初回の読み込み失敗、接続失敗、他端末の先行更新では送信を停止します。

## 4. 成績・履歴・共有

成績は端末の履歴に保存済みのセットを集計し、未保存の進行中入力は含めません。DB保存が未完了の場合、公開成績にはまだ反映されません。レーティング・個人成績も同じ保存済みセットを対象にします。期間・種目で絞り込み、見出しで並べ替えられます。プレイヤー名から順位分布、対戦相手別成績、ポイント・チップ・収支とRの推移を確認できます。

履歴には進行中セットも表示します。過去セットの「編集」から入力へ移り、「セットを保存」で修正を反映します。編集を取り消す前の内容も復旧用に保護します。

保存済みセットでは進行中でも共有リンクを利用できます。DB保存・公開反映の完了を確認してから共有してください。同じ日付・伝票番号が重複する場合はリンクを表示しません。既存の共有URLは継続利用できます。

## 5. 設定とデータの復旧

「JSON保存／読込」は現在のセットだけ、「全データをバックアップ／バックアップから復元」は現在のセット・履歴・プレイヤーマスターが対象です。全データの復元は件数を確認してから端末とDBに反映する操作です。復元前の端末データも保護します。

「復旧コピーを書き出す」は、改修前・DB読み込み前・送信前などの複数コピーをまとめた復旧ファイルを出力します。このファイルは通常の全データバックアップとは形式が異なります。内容の確認・支援を受ける際にも使えます。

「復旧コピーから端末に戻す → コピーの一覧を表示」で日時とセット数を確認し、「選んだコピーを端末に戻す」で復元できます。こちらはDBには自動送信しません。内容を確認したあと、必要な場合だけ「入力を保存・保存を再試行」を押してください。

コピーは同じブラウザの端末内に保持されます。ブラウザのデータ削除や端末故障では失われ得るため、全データのバックアップと復旧コピーの書き出しも利用してください。復旧コピーを作れない場合は、DBデータの読み込みによる置換・送信を止めます。

## 6. ログアウトとルール

上部の「この端末からログアウト」を押します。未送信入力があれば、保護してログアウトするか確認します。DBへは勝手に送信しません。他の端末のログインは維持します。端末内のデータは旧版との互換性・入力保護のため残りますが、改修版の管理画面はログインしないと開けません。端末データの暗号化を提供する仕組みではありません。

[ルール・点数表](https://taikechiuketa.github.io/mahjong-score/rules.html)はログインなしで参照できます。編集は記録画面とログインを共通利用します。保存前に旧本文を端末へ保護し、公開前の確認を表示します。
